# Финальное ревью версии 1.1

Дата: 13.10.2026. Версия закрывает сезонное исследование краткосрочного прогноза высоты; новое направление продолжается отдельно в 1.2.

## Зафиксированный результат

Три независимых обучения: LFPG 09L, EGLL 09L, EDDF 07L. В каждом аэропорту 15 погожих дней 2025 года, по пять весной, летом и осенью. Всего 8788 пригодных заходов и 279153 наблюдаемые пары. Polynomial Ridge степени 2 дает минимальную общую тестовую MAE среди проверенных моделей каждого аэропорта: 17.16, 15.45 и 20.87 ft. Итоги, погода и ограничения: [research/RESULTS.md](research/RESULTS.md).

## Что проверено

- Все 14 выполненных ноутбуков: схема документа, исполнение непустых ячеек, отсутствие ошибок
- Сезонные даты, погодное покрытие, объемы, разделение обучения/валидации/теста
- Сохраненные прогнозы общих моделей всех трех аэропортов и соответствие итоговым MAE
- Начальные исследования LFPG: один день, сравнение моделей, четыре дня
- Локальные ссылки, синтаксис Python и отсутствие сырых данных, моделей, статей и чекпоинтов среди отслеживаемых файлов
- Локальная статья 05: таблицы, графики, формулы, контрольные суммы источников и исключение из Git

При ревью исправлены устаревшее описание проекта в README и отсутствие `metar`/`orjson` в общих зависимостях. Ранние проверки контрольных сумм учитывают только замену окончаний строк LF/CRLF в UTF-8 тексте; содержательные изменения и бинарные данные проверяются по прежним SHA256. Исторические манифесты не переписаны.

Проверка сохраненных прогнозов требует локальных данных и моделей, которые не входят в Git. Получение новых архивов и переобучение в финальном ревью не выполнялись. Требования отдельных сезонных исследований сохранены рядом с их инструкциями.

## Границы закрытия

Проверен прогноз наблюдаемой высоты на 30 ± 3 секунды, не полная траектория и не вероятность ухода на второй круг. Одна тестовая дата на сезон ограничивает обобщение; статистическая значимость не оценена. Есть сезонные исключения, различие правил COR, неизвестное историческое время публикации METAR и неподтвержденная эксплуатационная применимость геометрии. Эти ограничения сохранены в выводах.

Удаленный репозиторий не настроен; публикация на GitHub не входит в закрытие. Результаты сохраняются в `main`. Локальные статьи, данные и чекпоинты остаются в папке проекта и исключены из Git. Версия 1.1 сохраняется как завершенная точка отсчета; следующий эксперимент следует сначала определить для 1.2.
