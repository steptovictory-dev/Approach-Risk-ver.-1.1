# Хитроу: сезонное обучение простых моделей

Повтор сезонного эксперимента LFPG для EGLL 09L: по пять погожих дней весны, лета и осени 2025 года. Проверяем краткосрочный прогноз высоты и сравниваем Ridge, Polynomial Ridge, Huber и ElasticNet с постоянной вертикальной скоростью. Модели обучаются отдельно для Хитроу; перенос готовой модели Парижа здесь не проверяется.

Ветка `research/egll-seasonal-learning` создана от актуального `main`. Предыдущая ветка `research/egll` сохранена.

В каждом сезоне первые три выбранных по дате дня используются для обучения, четвертый для валидации, пятый для теста. Параметры выбираются по валидации; тестовые дни одинаковы для всех моделей. Каждый заход имеет одинаковый суммарный обучающий вес. Проверяем также обучение на одном, двух и трех днях.

Погода должна подходить весь интервал 08:00–18:00 Europe/London: видимость от 10 км, BKN/OVC/VV от 3000 ft, ветер до 15 kt, порывы до 25 kt, температура от -10 до +30 C, без неблагоприятных явлений и неизвестных условий. Требуем минимум десять пригодных заходов и 300 пар на день. Назначение полосы определяется по траектории, направление ветра используется только для очередности поиска.

Прогноз высоты через 30 ± 3 секунды использует девять признаков из предыдущих наблюдений до барометрического прокси 300 ft. Для QNH принята условная задержка доступности 15 минут. В отличие от LFPG, здесь включены архивные METAR с COR: в EGLL ими помечено большинство сообщений. Архив не подтверждает время публикации исправления, поэтому доступность QNH является допущением, а не доказанной исторической причинностью. Остальные настройки сохранены из LFPG. Это высотная динамика, а не оценка вероятности ухода на второй круг.

## Повторить

Из корня репозитория:

```powershell
python -m pip install -r research/egll-seasonal-learning/requirements.txt
python research/egll-seasonal-learning/scripts/select_weather.py 2025
python research/egll-seasonal-learning/scripts/collect_seasons.py
```

Сбор сначала использует подходящие суточные архивы из `research/lfpg-seasonal-learning/data`, затем загружает недостающие ADSB.lol. Повторный запуск использует сохраненные траектории и пары. Только обучение на готовых данных: `python research/egll-seasonal-learning/scripts/train_models.py`. Обновление представления: `python research/egll-seasonal-learning/scripts/build_training_notebook.py`.

Источники: [ADSB.lol 2025](https://github.com/adsblol/globe_history_2025), [METAR IEM](https://mesonet.agron.iastate.edu/request/download.phtml), [OurAirports runway data](https://github.com/davidmegginson/ourairports-data). Геометрия и источник сохранены в `airports/EGLL/reports/`; это справочник для исследования, а не подтверждение исторических эксплуатационных условий.

## Результат

Собрано 15 дней, 5601 пригодный заход и 166508 наблюдаемых пар. Общая Polynomial Ridge дала MAE 15.45 ft против 55.95 ft у baseline на 1136 заходах трех отложенных дней. В LFPG минимальная ошибка также была у Polynomial Ridge.

[Выводы и сравнение аэропортов](reports/RESULTS.md), [отбор дней](notebooks/01_seasonal_days.ipynb), [выполненное обучение](notebooks/02_seasonal_training.ipynb). Проверка сохраненных прогнозов и высотной привязки: `python research/egll-seasonal-learning/scripts/verify_results.py`. Суточные глобальные архивы занимают несколько гигабайт; повторный сбор использует локальные файлы.
